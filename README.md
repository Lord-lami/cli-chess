# cli-chess
A command line interface chess game.

## Usage
1. Check that python3 is installed on your operating system by running
```bash
python3 --version
```
2. Run:
```bash
python3 play.py
```

3. To load the last saved game:
```bash
python3 play.py load
```

4. To use the timer:
```bash
python3 play.py -t 30
```
